# Datheon Python Programming Internship

## About
This repository contains four Python projects developed as part of the Datheon Python Programming Internship.

## Projects

### 1. Hangman Game
A console-based word guessing game with six attempts, random word selection and ASCII graphics.

### 2. Stock Portfolio Performance Tracker
A Python application that calculates investment values, profit and loss, and saves portfolio summaries to CSV.

### 3. Automated File Organizer
A utility that automatically organizes files into folders based on their extensions using Python OS and Shutil libraries.

### 4. Rule-Based Interactive Chatbot
A terminal-based chatbot that recognizes keywords and responds to greetings, product questions, business hours and other queries.
