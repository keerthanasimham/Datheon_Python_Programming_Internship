# Rule-Based Interactive Terminal Chatbot

## Description
A Python terminal chatbot that responds to user questions using keywords and regular expressions.

## Features
- Greeting responses
- Business hours information
- Product FAQs
- Contact information
- Thank-you responses
- Unknown query handling
- Exit commands

## Technologies Used
- Python
- Regular Expressions (re)
- Dictionaries
- Conditional Statements
- Loops

## How to Run
1. Install Python.
2. Open the project folder.
3. Run: python chatbot.py
4. Type a question to chat with the assistant.
5. Type bye to exit.
