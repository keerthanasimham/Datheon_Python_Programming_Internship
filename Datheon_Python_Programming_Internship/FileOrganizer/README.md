# Automated File Organizer

## Description
A Python utility that organizes files into folders based on their file extensions.

## Features
- Automatically identifies file types.
- Creates category folders.
- Moves files into suitable folders.
- Handles duplicate filenames.
- Handles permission errors.
- Displays an execution summary.

## Technologies Used
- Python
- OS module
- Shutil module

## How to Run
1. Install Python.
2. Open the project folder.
3. Run: python organizer.py
4. Enter the folder path you want to organize.

## Safety
Test the program using a sample folder before organizing important files.
