# Hangman Game

## Description
A Python-based console Hangman game where players guess a hidden word letter by letter.

## Features
- Random word selection
- Six incorrect attempts
- ASCII Hangman graphics
- Tracks guessed letters
- Prevents duplicate guesses
- Win and lose conditions

## Technologies Used
- Python
- Random module
- Loops
- Conditional statements
- String manipulation

## How to Run
1. Install Python.
2. Open the project folder.
3. Run: python hangman.py
