# Stock Portfolio Performance Tracker

## Description
A Python application that tracks stock investments and calculates portfolio performance.

## Features
- Enter stock ticker symbols.
- Record buying prices and share quantities.
- Calculate current portfolio value.
- Calculate profit and loss.
- Calculate percentage gain or loss.
- Save portfolio summaries to CSV.

## Technologies Used
- Python
- CSV module
- File Handling
- Dictionary

## How to Run
1. Install Python.
2. Open the project folder.
3. Run: python portfolio.py
4. Enter stock details when prompted.
5. Type DONE to finish.

## Note
Current stock prices are entered manually.
